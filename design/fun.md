# ともしび めいろ — 面白さの設計(M0)

パックマン風の迷路。光の計算は2D Radiance Cascades(RC)。**エサが光源**で、食べるほど迷路が暗くなる。おばけはRCで計算した「その地点の明るさ」をGPUから読み戻して、明るい所に入れない・焼ける。

## 1. 狙う体験
1. **4 緊張と緩和** — 最初はエサの光で迷路じゅうが明るく安全。食べるほど暗がりが広がり、自分が食べた跡=暗い道をおばけが追ってくる(後半ほど怖い)。
2. **ためて一気に解放**(息子が夢中になる型) — 食べたエサの光は自分の中にたまる。ためるほど大きな閃光になり、まわりのおばけを一気に焼く。
3. **6 発見** — 残したエサは光の壁になる。どこを残し、どこから食べるかで、おばけの通り道が変わる(光で地形を作る)。

## 2. 核のルール(候補と選んだ理由)
| 案 | 中身 | 1 怖さが育つ | 2 ためて解放 | 3 光の判断 | 子どもに一言で伝わるか |
|---|---|---|---|---|---|
| A そのままパックマン | エサが光るだけ。パワーエサ=一定時間おばけが逃げる | ○ | × | △ | ○ |
| **B 光をためる(採用)** | 食べたエサの光が「ともしび」にたまる。好きな時に放つ=閃光。ためるほど大きい。閃光の跡にしばらく残り火 | ○ | ◎ | ○ | ○「たべた ひかりを ためて ドーン」 |
| C 光を置く | エサを運んで好きな所に置き直す | △ | × | ◎ | △ 操作が増える |

- B を核にし、A のパワーエサを「大きな光の玉=食べるとともしびが満タン」として残す(見た目で分かる強い光=そこは安全地帯、食べるか残すかの判断)。C は操作が増えるので見送り。
- **おばけのルールは1つ**: 明るい所には入れない(ためらう)、もっと明るいと焼ける。焼けたおばけは目だけになって巣に戻り、しばらくして出てくる。判定は全部RCの明るさ(壁の影・反射光・残り火も効く)。
- 1面 = エサを全部食べたらクリア。最後の数個は真っ暗な迷路で取りに行くことになる。

## 3. つまみ
`lib/tuning.ts`: PELLET_E / POWER_E(エサの光)、GHOST_FEAR / GHOST_BURN / GHOST_BURN_DPS(おばけと光)、CHARGE_PER_PELLET / CHARGE_MAX / BURST_MIN / BURST_E / EMBER_SEC(ためて解放)、PLAYER_SPEED / GHOST_SPEED / GHOST_SPEED_PER_STAGE(速さ)、FOG / BOUNCE(光の届き方)。

## 4. ボットで見るもの(面白さの採点には使わない)
- 詰みがないか(クリアできる面か)、難しさの目安(クリア率・平均生存時間)、決定性。数値を目的にしない。
